MinIO is a high-performance, S3-compatible object storage server. This guide takes you from zero to a running instance with bucket operations in under five minutes.

<Warning>
  The community edition is now **source-only**. Pre-compiled binaries are no longer published. You must build from source or use Docker. See [Install from source](/install/from-source) or [Docker deployment](/install/docker).
</Warning>

## Start a single-node server

<Steps>
  <Step title="Install the binary">
    Requires Go 1.24 or later. Run:

    ```sh
    go install github.com/minio/minio@latest
    ```

    Confirm the binary is on your `PATH`:

    ```sh
    minio --version
    ```
  </Step>

  <Step title="Start the server">
    Pass any empty directory as the storage path:

    ```sh
    minio server /data
    ```

    To pin the console to a fixed port (recommended), use `--console-address`:

    ```sh
    minio server /data --console-address :9001
    ```

    MinIO binds the S3 API on port **9000** and the web console on **9001** (or a random port if `--console-address` is not set).
  </Step>

  <Step title="Open the web console">
    Point your browser to [http://127.0.0.1:9000](http://127.0.0.1:9000) and log in with the default root credentials.

    <Warning>
      The default credentials are `minioadmin` / `minioadmin`. Change them before exposing MinIO to a network by setting the `MINIO_ROOT_USER` and `MINIO_ROOT_PASSWORD` environment variables before starting the server.
    </Warning>

    From the console you can create buckets, upload objects, and browse stored data.
  </Step>

  <Step title="Connect with the mc client">
    Install the MinIO Client (`mc`) and verify connectivity:

    ```sh
    mc alias set local http://localhost:9000 minioadmin minioadmin
    mc admin info local
    ```

    Create a bucket, copy a file, and list its contents:

    ```sh
    mc mb local/my-bucket
    mc cp ~/Downloads/mydata local/my-bucket/
    mc ls local/my-bucket/
    ```
  </Step>
</Steps>

## Using the mc client

The `mc` command-line tool provides Unix-style commands (`ls`, `cp`, `mb`, `mirror`, `diff`) for any S3-compatible endpoint.

### Set an alias

An alias stores connection details so you don't repeat credentials on every command:

```sh
mc alias set local http://localhost:9000 minioadmin minioadmin
```

### Common operations

```sh
# Create a bucket
mc mb local/my-bucket

# Copy a local file into a bucket
mc cp ~/Downloads/mydata local/my-bucket/

# List objects in a bucket
mc ls local/my-bucket/

# Show server diagnostics
mc admin info local
```

## Ports reference

| Port | Purpose |
|------|---------|
| 9000 | S3 API and web console (default) |
| 9001 | Dedicated console port when `--console-address :9001` is set |

<Note>
  MinIO runs the console on a random port by default. Use `--console-address` to choose a specific port for reproducible access.
</Note>
